## 有意差异

- 概念稿用五行静态示例；实装只显示真实求解得到的一行，避免伪造结果丰富度。
- 概念稿中的数值偏展示；实装显示合成 fixture 经过当前公式计算的数值。
- 固定项默认文案由“固定某槽”改为“自动选择”，更准确表达可选锁定。
- 实装缩小了字体和留白，以便 1264×985 视口无需横向滚动即可完成主要操作。

## 已验证交互

- 载入示例账号并填充角色、神器和六个槽位。
- 64 套精确枚举；默认约束返回 1 套可行解。
- 锁定头盔后候选集缩小，并正确返回重击率理论上限诊断。
- 极端攻击约束返回“攻击理论最高”诊断。
- 浏览器 console 无 error 或 warning。
- 新增“满暴攻击×爆伤代理”后，默认条件列表不含手工重击率约束仍精确枚举 64 套，仅返回重击率 100.0% 的一套；目标分数 `1,210.01` 与 `627 × (1 + 0.93)` 一致。固定 `helm-002` 后枚举 32 套并诊断“重击率理论最高 85.0%”。两次交互 console 均无 warning/error。

以上只证明产品闭环和求解器原型工作；不证明属性公式或种子数据等同于当前游戏客户端。

后续功能回归：配装条件已从四个固定字段扩展为动态约束行，同时保留原概念的左侧固定项、右侧条件/结果层级、暖金主操作和表格驱动布局。1440×900 桌面与 390×844 移动端均通过隐藏 IAB 检查；移动端约束属性标签无截断、无横向溢出。

### 有意差异

- 概念中的“游戏装备详情”是设计占位，不作为可验证证据。实装示例显示仓库已有的合成求解器截图；待真实脱敏游戏截图到位后再建立 golden set。
- 概念显示 17 张截图，实装示例仅 1 张，避免用伪造批量数据制造完成度；真实 recognition bundle 支持任意多张。
- 实装导出的是 Review 决策，不直接声称已生成最终账号快照，因为页面布局解析尚未用真实游戏样本验证。

最终实装与概念的结构、信息层级、配色、字体、边界、操作层级和响应式意图一致；没有剩余可修复的重大视觉偏差。核心路径“载入示例 → 发现歧义 → 阻止接受 → 选择候选 → 接受”已验证，browser console 无 warning/error。
