# 待验证问题

## P0 — 阻塞正确实现

1. 首个目标渠道是国服 PC、国服模拟器/Android、国际服 PC、Steam 还是多个？
2. 国服当前版本的七槽位、强化上限、主副词条池和套装阈值是否与公开国际资料一致？
3. 角色攻击/生命/防御百分比的精确结算顺序是什么？神器固定值是否进入百分比基数？
4. 是否存在官方账号数据导出、个人数据下载、公开 API 或游戏内分享码？
5. 自动导入是硬发布条件，还是可接受首版批量截图/JSON？
6. 国服当前客户端是否能提供稳定角色 ID，或可与国际服角色唯一对应的图标、技能、元素和稀有度组合？

## P1 — 影响产品质量

7. 国服 UI 对 `Accuracy`、`Enlightenment`、`Crit Rate`、`Crit Damage` 的当前官方中文分别是什么？
8. 所有角色是否共享 10% 基础重击率和 50% 基础重击伤害？哪些成长节点会改变它们？
9. 重击率超过 100% 是否完全浪费，是否存在溢出转换神器/角色效果？
10. 同名 `+` 装备、神话单件与传说三件套在国服当前版本如何标识和叠加？
11. 套装 2 件/3 件、重复 2 件套、神话单件效果的精确计数规则是什么？
12. 正/负符文的主词条与副词条池、互斥规则和强化次数分别是什么？
13. 装备在账号内是否有可见稳定 ID；如果没有，merge 应用什么复合指纹？

## P2 — 后续增强

14. 哪些神器/套装的条件效果值得进入首批技能模板？
15. 用户常用战斗场景的敌方防御、抗性、战斗时长和队伍 buff 如何参数化？
16. 多角色联合优化更常见的是 5 人小队、若干首领队，还是整个账号逐角色分配？
17. 是否需要中英文/繁中数据包和别名共同支持？
18. 公开发布时可使用哪些游戏名称、图标、角色/装备图片和数据集？

## 需要的最小样本

- 当前目标客户端的版本号与渠道截图；
- 5–10 个角色完整面板与成长状态；
- 30–50 件不同槽位/品质/强化等级的装备详情；
- 10 件不同品质和精炼等级的神器；
- 3 套穿戴前后面板对照，包含固定值与百分比词条。
